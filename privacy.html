Политика конфиденциальности

Актуально с 6 ноября 2026 года. Эта политика описывает подключение YouTube-канала для публикации роликов Salergood.

Какие данные используются

Владелец канала однократно предоставляет приложению разрешение youtube.upload. Google выдаёт токен для загрузки видео в выбранный канал. Мы не запрашиваем доступ к письмам, контактам, файлам Google Drive или данным зрителей YouTube.

Для чего используется доступ

Токен применяется только для загрузки созданных проектом коротких роликов и проверки статуса их публикации через YouTube Data API. Опубликованные видео, их названия и описания становятся общедоступными на YouTube.

Хранение и передача

Токен и данные OAuth-клиента хранятся в закрытых GitHub Actions Secrets репозитория проекта. GitHub Actions использует их для запуска публикации; Google получает запросы на авторизацию и загрузку. Мы не продаём данные Google, не используем их для рекламного таргетинга и не передаём их другим получателям.

Отзыв доступа и удаление

Владелец может в любой момент отозвать доступ приложения в Google-аккаунте. После отзыва новые ролики не смогут публиковаться, пока владелец снова не разрешит доступ. Для запроса об удалении сохранённого токена или опубликованного видео откройте обращение к проекту; не размещайте в публичном обращении пароли и токены.

Изменения

При изменении способов работы с данными Google эта страница будет обновлена до использования новых способов.
